### **ASSIGNMENT 1: MS WORD**

**1. Explain the term word processor**
A word processor is a software application used to create, edit, format, and print text-based documents. It allows users to type, store, and manipulate text digitally.

**2. Explain the difference between word processing software and traditional typewriters**
*   **Editing:** Word processors allow easy editing (delete, insert, copy, move text) before printing. Typewriters require retyping the entire page for corrections.
*   **Storage:** Word processors save documents digitally for future use. Typewriters produce only physical paper copies.
*   **Formatting:** Word processors offer multiple fonts, sizes, colors, and layouts. Typewriters have fixed fonts and no layout flexibility.

**3. List types of word processors**
*   Microsoft Word
*   Google Docs
*   Corel WordPerfect
*   Apple Pages
*   LibreOffice Writer
*   WPS Office Writer

**4. Using a well labelled diagram, draw and identify components of a word processing window**
*(Note: I cannot draw, but here is the list of components you should label in your diagram)*
*   **Title Bar:** Shows the document name and program name.
*   **Menu Bar/Ribbon:** Contains tabs (File, Home, Insert, etc.) with command buttons.
*   **Ruler:** Shows margins and tab stops.
*   **Workspace/Document Area:** The main area where you type text.
*   **Scroll Bars:** Used to move up/down or left/right in the document.
*   **Status Bar:** Shows page number, word count, and zoom level.
*   **Cursor/Insertion Point:** The blinking line where text will appear.

**5. List the formatting features used in MS Word**
*   Font type, size, and color
*   Bold, Italic, Underline
*   Text alignment (Left, Center, Right, Justify)
*   Bullets and Numbering
*   Line and Paragraph spacing
*   Indentation
*   Borders and Shading
*   Styles and Themes

**6. Differentiate between a header and a footer**
*   **Header:** Appears in the top margin of a page. It usually contains titles, chapter names, or logos.
*   **Footer:** Appears in the bottom margin of a page. It usually contains page numbers, dates, or footnotes.

**7. Define mail merge**
Mail merge is a feature that combines a main document (e.g., a letter) with a data source (e.g., a list of names and addresses) to produce multiple personalized documents.

**8. Identify three documents involved in mail merge**
1.  **Main Document:** The standard letter or template containing the boilerplate text.
2.  **Data Source:** The list of information (names, addresses, etc.) usually stored in Excel or Access.
3.  **Merged Document:** The final output containing the personalized letters.

**9. State the output of each keyboard key combination**
*   **i. Ctrl + C:** Copy selected text.
*   **ii. Ctrl + Z:** Undo the last action.
*   **iii. Ctrl + F4:** Close the active document window (without closing the app).
*   **iv. Ctrl + A:** Select all text in the document.
*   **v. Ctrl + B:** Bold the selected text.
*   **vi. Ctrl + X:** Cut (remove and copy) selected text.
*   **vii. Ctrl + V:** Paste copied/cut text.
*   **viii. Ctrl + F:** Open the Find search box.
*   **ix. Ctrl + H:** Open the Find and Replace dialog box.
*   **x. Ctrl + S:** Save the document.
*   **xi. Ctrl + P:** Open the Print dialog box.

**10. State FOUR type cases in MS Word**
1.  **Sentence case:** Capitalizes the first letter of the first word in a sentence.
2.  **lowercase:** Changes all selected text to small letters.
3.  **UPPERCASE:** Changes all selected text to capital letters.
4.  **Capitalize Each Word:** Capitalizes the first letter of every word.
5.  **tOGGLE cASE:** Switches the case of each letter (e.g., "Hello" becomes "hELLO").

**11. Differentiate between save and save as**
*   **Save:** Updates the existing file with any new changes. It overwrites the current file.
*   **Save As:** Creates a new copy of the file. It allows you to change the file name, format, or location without altering the original file.

### **ASSIGNMENT 2: MS EXCEL**

**1. Define Spreadsheet**
A spreadsheet is a computer application that simulates a paper accounting worksheet. It organizes data in rows and columns and allows for calculations using formulas.

**2. Importance of Spreadsheets**
*   Data organization and storage.
*   Performing complex mathematical calculations automatically.
*   Creating charts and graphs for data visualization.
*   Analyzing data (e.g., what-if analysis).
*   Budgeting and financial planning.

**3. a) Using a well labelled diagram identify the different parts of an MS Excel document**
*(List of parts to label)*
*   **Title Bar:** Name of the workbook.
*   **Ribbon/Tabs:** Tools and commands.
*   **Name Box:** Shows the active cell address (e.g., A1).
*   **Formula Bar:** Where you type or view formulas/data.
*   **Column Headers:** Letters (A, B, C...) at the top.
*   **Row Headers:** Numbers (1, 2, 3...) on the left.
*   **Active Cell:** The selected cell with a thick border.
*   **Sheet Tabs:** Tabs at the bottom (Sheet1, Sheet2).
*   **Status Bar:** Shows average, count, and sum of selected cells.

**3. b) Explain the parts labelled above**
*   **Formula Bar:** Displays the contents of the active cell.
*   **Name Box:** Shows the address of the selected cell.
*   **Active Cell:** The cell currently selected for data entry.
*   **Sheet Tabs:** Used to switch between different worksheets in a workbook.

**4. Define a cell**
A cell is the intersection of a row and a column. It is the basic unit of a spreadsheet where data is entered.

**5. Differentiate between a row and a column**
*   **Row:** A horizontal group of cells, identified by numbers (1, 2, 3).
*   **Column:** A vertical group of cells, identified by letters (A, B, C).

**6. Using an example explain a range of cells**
A range is a selection of two or more cells. Example: **A1:B5** refers to all cells from A1 to B5 in a rectangular block.

**7. Differentiate between a workbook and a worksheet**
*   **Workbook:** The entire Excel file (the book). It can contain many pages.
*   **Worksheet:** A single page inside the workbook (the sheet). It is where you actually enter data.

**8. Explain 8 data types used in Excel. Provide an example for each.**
1.  **Text:** "Hello World"
2.  **Number:** 123, 45.67
3.  **Date:** 12/10/2023
4.  **Time:** 10:30 AM
5.  **Currency:** $100.00
6.  **Percentage:** 50%
7.  **Boolean:** TRUE / FALSE
8.  **Error:** #DIV/0!

**9. Differentiate between moving and copying a worksheet**
*   **Moving:** Relocates the sheet to a new position or file, removing it from the original location.
*   **Copying:** Duplicates the sheet, leaving the original in place and creating a new identical copy.

**10. Explain 7 alignments used in Excel**
1.  **Top Align:** Aligns text to the top of the cell.
2.  **Middle Align:** Centers text vertically in the cell.
3.  **Bottom Align:** Aligns text to the bottom of the cell.
4.  **Left Align:** Aligns text to the left edge.
5.  **Center Align:** Centers text horizontally.
6.  **Right Align:** Aligns text to the right edge.
7.  **Wrap Text:** Breaks long text into multiple lines within a cell.

**11. Differentiate between a function and a formula. Provide an example for each**
*   **Formula:** A user-created equation using operators (e.g., `=A1+A2`).
*   **Function:** A predefined built-in formula (e.g., `=SUM(A1:A2)`).

**12. Using an example, explain the following functions:**
*   **a) SUM:** Adds all numbers in a range. `=SUM(A1:A5)`
*   **b) AVERAGE:** Calculates the mean. `=AVERAGE(A1:A5)`
*   **c) MINIMUM:** Finds the smallest number. `=MIN(A1:A5)`
*   **d) MAXIMUM:** Finds the largest number. `=MAX(A1:A5)`
*   **e) COUNT:** Counts cells containing numbers. `=COUNT(A1:A5)`
*   **f) COUNTA:** Counts non-empty cells. `=COUNTA(A1:A5)`
*   **g) COUNTIF:** Counts cells meeting one criterion. `=COUNTIF(A1:A5, ">50")`
*   **h) SUMIF:** Adds cells meeting one criterion. `=SUMIF(A1:A5, ">50")`
*   **i) IF:** Returns one value if true, another if false. `=IF(A1>50, "Pass", "Fail")`

**13. Using appropriate examples, define the following:**
*   **a) Relative referencing:** Cell references change when copied. (e.g., Copying `=A1` to B2 becomes `=B2`).
*   **b) Absolute referencing:** Cell references do not change. Uses `$`. (e.g., `=$A$1` stays `=$A$1`).
*   **c) Mixed cell referencing:** Either the row or column is fixed. (e.g., `=$A1` or `=A$1`).

**14. Differentiate between a header and a footer**
*   **Header:** Printed at the top of every page.
*   **Footer:** Printed at the bottom of every page.

**15. Explain types of header sections**
Headers are divided into three sections: **Left**, **Center**, and **Right**. You can insert different information (page numbers, titles, dates) into each section.

**16. Define a chart**
A chart is a graphical representation of data. It uses symbols like bars, lines, or pies to make data easier to understand.

**17. Explain 5 types of charts used in Excel**
1.  **Column Chart:** Uses vertical bars to compare values.
2.  **Line Chart:** Shows trends over time.
3.  **Pie Chart:** Shows proportions of a whole.
4.  **Bar Chart:** Uses horizontal bars to compare values.
5.  **Scatter Plot:** Shows relationship between two variables.

**18. Define 10 chart elements**
1.  **Chart Title:** Name of the chart.
2.  **Axis Title:** Labels for X and Y axes.
3.  **Legend:** Explains what colors/symbols represent.
4.  **Data Labels:** Numbers/text on the bars/lines.
5.  **Gridlines:** Horizontal/vertical lines for reading values.
6.  **Plot Area:** The area where data is plotted.
7.  **X-Axis:** Horizontal axis (Category).
8.  **Y-Axis:** Vertical axis (Value).
9.  **Data Series:** The actual bars/lines representing data.
10. **Chart Area:** The entire chart including titles and legend.

**19. Explain the types of errors in MS Excel. Give an example for each.**
1.  **#DIV/0!:** Division by zero. (e.g., `=5/0`)
2.  **#N/A:** Value not available. (e.g., VLOOKUP can't find value).
3.  **#NAME?:** Unrecognized text in formula. (e.g., `=SUMM(A1:A5)` - typo).
4.  **#NULL!:** Intersection of two areas that don't intersect. (e.g., `=A1 B1` with space).
5.  **#NUM!:** Invalid numeric value. (e.g., `=SQRT(-1)`).
6.  **#REF!:** Invalid cell reference. (e.g., deleting a column referenced in a formula).
7.  **#VALUE!:** Wrong data type. (e.g., adding text to a number: `="A"+1`).
